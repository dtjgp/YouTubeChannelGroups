# 设计与网页质量要求

生效日期：2026-10-18。适用于本项目之后的设计和实现变更。

用户要求严格遵守 [Chrome Modern Web Guidance disciplines](https://developer.chrome.com/docs/modern-web-guidance/disciplines)。其中适用的规范作为验收要求；未检查、未完成和不适用的内容必须分别说明，不能用自动检测分数替代完整验收。

苹果玻璃材质、Chrome 控件习惯和 YouTube 实时主题继续作为外观约束。可读性、操作可达性和页面性能优先于材质效果。指南不是固定的配色、圆角或图标样式表。

## 适用范围

| 规范 | 本项目的验收要求 |
| --- | --- |
| Accessibility | 正确语言、原生语义、稳定可见焦点、持久标签、错误提示；键盘完成分类和审核；触控目标；缩放、重排、对比度和辅助技术验证 |
| HTML | 原生按钮、链接、表单、列表、披露控件；有效名称和层级；隐藏内容退出焦点顺序 |
| CSS | 复用语义变量、限制样式范围、管理优先级；支持主题、减少动态效果、减少透明和强制颜色偏好 |
| CSS layout | 按可用空间重排，避免横向裁切；移动和缩放后保留可操作区域；长内容能滚动访问 |
| Forms | 标签与控件关联；提示通过 `aria-describedby` 关联；原生约束及字段错误定位；验证失败保留输入；防止重复提交 |
| Performance | 高频事件合并处理，测量并拆分超过 50 毫秒的扩展任务；用真实 YouTube 对照测试评估交互、玻璃合成及布局影响 |
| Privacy | 默认本机保存，按需明确发送 AI 数据；最小权限、导出、纠正和删除；不得加入跟踪或发送密钥到网页 |
| Security | 不可信内容按文本写入；校验消息来源、网址、备份及模型输出；本地脚本、安全策略、密钥隔离、请求超时和响应上限 |
| Chrome extensions | Manifest V3；持久数据在存储中，不能依赖后台常驻；运行时申请实际服务主机；保持固定扩展目录及 Native Messaging 来源限制 |

入口的 `css-layout` 原 GitHub 链接在本轮返回 404。布局暂参考 [web.dev Layout](https://web.dev/learn/css/layout) 并以浏览器实测核对；不能声称已读到缺失指南。

Passkeys、WebMCP、支付、广告、网站账户注册、音视频制作和商店发布目前不适用。扩展没有自有网站服务器，不能直接部署 YouTube 的 HTTP 安全头。扩展内容安全策略以 Chrome 的 MV3 规则为准。若产品范围变化，重新判断适用性。

## 验收流程

1. 读取本文件和最新审查报告，定位受影响的规范条款。
2. 为行为变化选择有效回归；纯文字或样式修改使用相应语义、布局或视觉检查。
3. 在临时浏览器配置中运行扩展。使用示例频道和模拟服务，不调用真实模型。
4. 检查中文／英文、浅色／深色、窄视口、焦点和偏好回退。保存本轮截图、扫描结果及未完成的人工项。
5. 检查实际差异，完成相关测试和包一致性检查，才交付版本。存在未关闭项时只能声明已完成的范围。

非模态面板允许继续操作 YouTube 视频，因此不把整页设为 `inert`，也不锁住页面焦点。标题栏及边框属于二维窗口操作区；它们使用自定义指针捕获。正文保留原生滚动。细边框提供同功能的四角目标和键盘入口，仍须触控人工验收。

## 悬浮窗口约束（v0.8.1）

用户要求始终覆盖在当前网页上。打开、关闭、移动、缩放或复位面板，不得为其预留侧栏空间，不得修改 YouTube 容器宽度、页面边距、视频尺寸或原有滚动位置。宿主退出正常文档流；只调整扩展自身的几何属性。点击网页时窗口保持打开，关闭按钮和 Esc 可收起，全屏时暂时隐藏。

验证须比较原页面和窗口打开前后的实际几何，覆盖宽屏、窄屏、复位和持久化；不能仅检查某个状态属性。主动选择分类的视频筛选仍属于用户明确操作，不属于面板打开的副作用。

本轮实现及证据见 [quality-v0.8.md](quality-v0.8.md)。v0.7.1 的原始审查仍保存在 [web-guidance-audit.md](web-guidance-audit.md)。下表按可执行证据更新，不覆盖历史结论。

| 项目 | 本轮结果 | 仍需保留的条件 |
| --- | --- | --- |
| 对比度 | 阅读区实色承载，派生文字颜色至少 4.5:1，控件边界及焦点至少 3:1；主要界面和自定义低对比主题扫描通过 | 400% 缩放的滚动裁切节点须滚入视口后逐项复查，不能将原始 incomplete 当通过 |
| 性能 | 后台查询、20 条频道分页、4 毫秒分帧、别名和审核索引；10000 频道／100 分类、4 倍 CPU 节流回归有明确门槛 | 真实 YouTube 对照属于单次匿名实验室测量，不能证明现场 Core Web Vitals 或所有设备无开销 |
| 键盘、缩放、触控 | 实际 200%／400% 浏览器缩放、可见焦点、八方向缩放、标题栏移动、48 像素粗指针普通控件通过 | 自动工具无法绑定临时原生窗口，VoiceOver 完整流程尚未完成；粗指针模拟不能替代真实触屏 |
| 删除和保留 | 确认框、可先导出、全量清除、撤销快照清除、旧请求／写入取消、暂停再收集、可选权限撤销及失败提示 | 只管理扩展自身数据；导出文件、AI 服务记录和 CLI 账号／会话须在对应位置管理。可选权限正／失败分支使用 API 合约测试，隔离浏览器验证实际无可选权限的删除路径 |
| CSS 架构和密度 | 共享设计变量、五个明确级联层、Shadow DOM 范围、相对字号、字段分组、短窗口折叠和分页 | v0.8.1 页面样式仅用于主动筛选和拖动光标；不得为悬浮窗口覆盖原布局 |
| Trusted Types | 已交付并通过真实扩展保存回归；只允许打包的后台脚本依赖；不安全 HTML 和脚本地址被阻止 | 不是完整安全审计，也不改变 YouTube 自身 HTTP 安全头 |
| 浏览器和页面变体 | 当前 Chromium 及一个真实匿名 YouTube 播放页通过 | Edge、Brave 独立实机和更多真实页面变体尚未完成 |

后续修改继续执行上述验收流程。VoiceOver、真实触屏、Edge／Brave 与现场性能仍是外部验收项；不能声明全部指南或全部 WCAG 条款已经符合。

## 最小化与频道头像（v0.9.0）

最小化只隐藏面板并显示小图标，不改变原网页布局，也不清空当前输入或审核。恢复时使用原来的位置、大小和操作状态。按钮须有中英文名称，支持 Enter／空格；隐藏面板须退出焦点顺序，全屏须隐藏小图标。最小化状态属于当前页面，位置／大小沿用已有持久化。

频道头像须从本频道的可识别头像区域读取，忽略简介提及和视频缩略图。图片地址在采集、导入与显示边界接受 HTTPS 官方图片主机白名单校验；远程图片无 Referer，延迟加载、固定占位并提供失败回退。头像与邻接名称重复时使用装饰语义。JSON 备份和删除流程包含头像地址，AI 数据不包含头像。

## 可拖动图标（v0.10.0）

最小化图标的几何与窗口几何分开保存。拖动图标不得改变恢复后的窗口位置、尺寸或原网页几何。松开后记住位置，同一浏览器配置的标签页同步。视口缩小只限制当前显示位置，不覆盖原偏好。

自定义拖动须区分点击，支持取消、指针捕获、键盘与粗指针，并在隐藏／失焦／尺寸变化时结束操作。图标边界依据实际控件尺寸；窄屏入口定位规则不得覆盖图标的拖动定位。图标位置须有输入校验，并纳入完整删除及旧操作保护。
