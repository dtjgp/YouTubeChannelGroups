# 最小化与频道头像 v0.9.0

日期：2026-10-19（Europe/Rome）。本轮从 2026-10-18 开始。保留苹果玻璃外框、实时 YouTube 主题和始终悬浮的布局。

## 已实现

- 标题栏新增“−”按钮。最小化后仅显示 44 像素圆形图标；粗指针下至少 48 像素。点击、Enter 或空格恢复窗口。
- 最小化保留位置、尺寸、输入、搜索和未应用的审核。全屏隐藏图标，退出后恢复收起状态。关闭按钮仍回到普通文字入口。
- 最小化状态仅属于当前页面。刷新后显示普通入口；位置和大小继续使用已有存储，不增加新的持久化键。
- 频道列表、普通 AI 建议和精简分类审核显示头像。固定 40 像素圆形区域，延迟加载；缺少图片或加载失败时显示名称前两个字符。
- 采集订阅频道卡片与当前频道主页的头像，并监听延迟加载和地址变更。忽略简介中的其他频道与视频缩略图。主页有空白占位标题时，读取后续非空标题或页面元数据。
- 地址在状态、导入和显示边界只接受 `yt3.ggpht.com`、`yt3.googleusercontent.com` 的 HTTPS URL，拒绝凭据、非默认端口、任意站点和脚本地址。图片请求使用 `no-referrer`。
- JSON 备份保留头像地址；旧备份兼容。缺失或非法的新头像不覆盖已有有效头像。合并频道别名时保留头像及分类。
- AI 输入仍只有原来的频道名称、地址、简介和分类要求，不发送头像。删除全部扩展数据同时清除头像地址和界面状态。
