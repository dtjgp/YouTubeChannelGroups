# v0.8 网页质量整改

日期：2026-10-18，Europe/Rome。范围为本次授权的对比度、性能、无障碍、完整数据删除和 CSS 架构。苹果玻璃外框、实时 YouTube 主题、标题栏移动及边框缩放均保留。没有调用用户模型账号、删除真实扩展数据或发布版本。

本轮工程整改及可执行验证已经完成。下面列出证据和边界；这不是完整 WCAG 或 Chrome 指南认证。

## 对比度与玻璃表面

原始 YouTube 配色仍保存在独立变量中。`design.js` 按背景计算文字、次要文字、链接、危险操作、边框及焦点颜色，必要时向黑色或白色调整。文字角色至少 4.5:1，控件边界及焦点角色至少 3:1。主文字在可达到时采用 7:1。不会修改 YouTube 自身的颜色设置。

玻璃模糊集中在 6 像素外框及阴影，标题、正文、审核和页脚使用不透明阅读背景。按钮使用与其底色匹配的颜色角色；设置页与面板共享算法。减少透明度及高对比度偏好会关闭模糊，强制颜色模式沿用系统颜色。

四个主要界面状态的 axe 扫描均无 violations 和 incomplete：中文浅色面板、审核工作台、320 像素英文深色审核、设置页。低对比灰色和相反明暗阅读／按钮背景也通过浏览器扫描。证据在 `artifacts/quality-v080/audit/`、`custom-theme.json`。

实际 400% 缩放扫描最初有两个被滚动边界裁切的文字节点，原因是 `elmPartiallyObscured`。测试将每个节点滚入视口后单独复查，结果均为零违规、零未解析项。原始结果和复查结果同时保留在 `zoom-400.axe.json` 与 `zoom.json`，没有忽略这些节点。

依据：[WCAG 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 列表性能

频道查询、排序和总数计算移到扩展后台。主列表每页 20 个频道，搜索覆盖全部已收集频道；分页不会减少 AI 处理范围。收起面板时不构建频道卡片。超过 20 类时，频道归属控件按需展开。

DOM 构建和视频筛选以约 4 毫秒为预算让出主线程，并检查取消标记。频道别名及审核频道使用索引，卡片身份使用 WeakMap 缓存；文字或链接改变会使相关缓存失效。审核计数单次汇总，主题观察与布局更新按动画帧合并。CSSOM 单独改色仍保留可见页面每秒补查。

受控大列表测试使用同一浏览器版本、10000 个频道、100 个分类及 4 倍 CPU 节流。基线为修改前 v0.7.1 的独立源码快照；改后执行打开、翻页、搜索及结果核对。

| 指标 | 修改前样本 | 修改后完整回归样本 |
| --- | --- | --- |
| 采样交互的最大 Event Timing 时长 | 1192 ms | 88 ms |
| 文档主线程观测到的长任务 | 1 个，74 ms | 0 个 |
| 搜索结果出现后，扩展内 DOM 节点 | 1187 | 695 |

回归要求改后没有观测到大于等于 50 毫秒的文档长任务，采样交互小于 200 毫秒。原始值保存在 `stress-before.json`、`stress.json`。Event Timing 不等于完整搜索完成时间；观测不包含后台 Service Worker 内部任务。CPU 节流不是另一台真实低性能设备，单次样本也不能证明现场 INP。

另以两个无登录的临时浏览器配置访问同一公开 YouTube 播放页，对照关闭及启用扩展。两种模式都加载了播放器和元数据，使用页面的拒绝 Cookie 按钮；启用模式实际打开、拖动及关闭面板。加载、布局位移、文档长任务和滚动帧间隔保存在 `real-web/comparison.json`。截图已检查。

两次导航的网络、缓存和 YouTube 内容各自变化，页面自身仍有长任务。不能把这组数据解释成扩展造成或消除了特定加载开销，也不能据此声称所有设备达到 Core Web Vitals。

## 无障碍与布局

界面采用原生列表、表单、字段分组、披露控件和确认对话框。增加跳到频道列表的入口、持久字段标签、关联错误说明、键盘窗口操作说明及密钥显示开关。关闭图标使用装饰性 SVG，按钮名称保持本地化。

实际 Chromium 缩放通过 `chrome.tabs.setZoom` 设置为 100%、200%、400%。对应 CSS 视口宽度为 1400、700、350 像素。键盘可勾选分类，保存后焦点仍在原控件，焦点能滚入可见区域。矮窗口折叠备份工具，正文保留滚动；网页高度不足 480 CSS 像素时，面板采用 12 像素上边距。粗指针模拟下普通控件至少 48 像素，四角及二维边框操作区至少 24 像素。

八方向真实鼠标命中、连续缩放、标题栏移动、取消、刷新保存、跨标签同步和页面避让均通过。已修复两个竞态：拖动结束产生的 click 不再触发键盘复位；拖动期间视口改变时，在指针移动／释放处也检查视口，防止 resize 事件稍晚到达时误保存尺寸。

VoiceOver 完整流程尚未完成。本机原生工具始终选择已有 Chrome for Testing 窗口，无法绑定独立临时窗口。未开启或改动用户的 VoiceOver 设置。只准备了示例数据测试窗口并完成清理，不能把它当成屏幕阅读器通过证据。记录在 `voiceover/walkthrough.json`。粗指针模拟也不能替代真实触屏验收。

## 完整数据删除

设置页的“数据与隐私”提供备份、完整删除和可选连接权限撤销。确认框默认聚焦取消，必须勾选确认项；删除失败和权限撤销失败分别显示结果。

删除覆盖全部扩展本地数据键：频道、分类、撤销快照、AI 地址和密钥、界面语言、主题缓存、面板位置及尺寸。先写入新的匿名删除标记，再删除其他键。标记包含一个随机操作代号及暂停收集状态，不含频道或账号。它用于拒绝删除前的旧写入，并保证刷新／重启后不自动重新收集；卸载扩展才移除此标记。

删除会中断云端 Fetch，断开 Native Messaging，清空已打开面板中的未应用预览。后台串行写入和页面操作代号阻止旧请求、待授权设置保存及备份读取任务重新写回。主题继续实时显示；暂停期间设置页通过内存消息同步颜色，不写回主题缓存。

浏览器实测确认：取消确认保留数据；未勾选不能删除；运行中的云端请求取消；只剩匿名删除标记；旧消息拒绝写入；多次刷新仍为空；主动恢复后才收集新频道。通过实际编译的本机主机和两个临时模拟 CLI，还分别验证了 Codex／Claude 请求取消后子进程退出。没有调用真实模型。

可选权限使用 `permissions.getAll/remove` 并读回核对。单元测试覆盖撤销成功、拒绝或异常、失败时数据仍被清除。隔离浏览器的本机模拟服务属于测试清单的必需权限，不可撤销，必须排除；实际无可选授权时的 UI 删除路径已验证。真实浏览器授权提示下的可选主机撤销仍需人工补验，不能把模拟合约当成已验证的原生提示体验。

扩展必需的 YouTube 内容脚本和 Native Messaging 权限不会被删除入口移除。已导出的文件、AI 服务收到的记录以及 CLI 自身的账号、会话和日志不属于扩展本地数据，界面和 README 已说明管理边界。

依据：[Chrome 权限 API](https://developer.chrome.com/docs/extensions/reference/api/permissions)、[Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)。

## CSS 架构与安全策略

`design.js` 是共享颜色、字号、间距、圆角、目标尺寸和字体变量来源。面板和设置页都声明五层顺序：`ycg.tokens`、`ycg.base`、`ycg.components`、`ycg.states`、`ycg.preferences`。偏好回退最后覆盖组件；主界面样式限制在 Shadow DOM，页面宽度及拖动光标覆盖集中在 `layout.js`。

小字提高到约 13 像素，基础字号使用相对单位并设置可读下限。设置页使用字段分组，长文本换行，矮窗口与分页减少密度。没有引入 CSS 框架或远程样式。

扩展页面启用 `require-trusted-types-for 'script'`，只允许 `ycg-bootstrap` 策略。后台通过精确文件名单加载已打包依赖，不接受页面或消息提供的脚本地址。真实浏览器验证普通设置保存成功，不安全的 HTML 写入、未批准策略和名单外脚本地址被拒绝。该策略不改变 YouTube 的安全头，也不是完整渗透测试。

## 验证和交付边界

通过 17 个运行文件语法检查、33 个逻辑测试、30 个完整隔离浏览器用例。最后调整少量颜色角色后，相关的三组浏览器检查再次通过。最后补充删除标记说明后，中英页面扫描和删除两组检查通过。真实 YouTube 对照另行显式运行并通过。完整离线套件的两个跳过项分别是显式联网检查和人工 VoiceOver 流程；前者已单独执行，后者仍受上述窗口绑定限制。

后续仍需：VoiceOver 全流程、真实触屏、可选主机授权／撤销的原生提示体验、Edge／Brave 独立实机和更多真实 YouTube 页面变体。真实模型分类质量和账号额度没有在开发中测试。没有变更必需权限、本机小助手或安装器。

本地已安装用户只需手动刷新同一个扩展，再刷新 YouTube。扩展目录不变，本机小助手无需重装。
