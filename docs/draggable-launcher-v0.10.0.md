# 可拖动小图标 v0.10.0

日期：2026-10-19（Europe/Rome）。本轮新增最小化图标的独立拖动与位置记忆，并准备项目的 GitHub 源码仓库。

## 行为

- 最小化后按住图标拖动，松开后记住位置。同一浏览器配置的 YouTube 标签页同步；刷新页面后再次最小化仍使用该位置。
- 图标位置单独保存在 `ycg.launcher-position.v1`，不写入窗口的 `ycg.panel-size.v1`。点击恢复时，窗口使用原来的位置、大小、搜索和未应用编辑。
- 点击与拖动以 6 CSS 像素阈值区分，拖动结束不误开窗口。普通点击及轻微手抖仍可恢复。
- 方向键移动 20 像素，Shift＋方向键移动 50 像素；Home 恢复默认图标位置，Enter／空格恢复窗口。帮助文本中英同步。
- Esc、失去指针捕获、失焦、视口变化和进入全屏均取消当前拖动。触控通过指针捕获与 `touch-action: none` 移动，不滚动原网页。
- 图标为 44 像素，粗指针下为 48 像素。显示位置保持在当前视口内；窗口缩小不覆盖原保存值，放大后恢复偏好。
- 完整数据删除同时清除图标位置、取消拖动和待保存任务，并拒绝旧 epoch 的写入。重置图标位置只删除该位置键，不修改窗口。
- 初始偏好读取完成后才启用入口；工具栏提前发起的打开请求随后执行，避免首次打开时读取到临时默认尺寸。窄屏普通入口定位规则已排除最小化图标，防止覆盖其独立位置。
