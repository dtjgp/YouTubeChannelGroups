数据与隐私

频道、分类、撤销记录及设置保留在此浏览器中，直到你删除。未应用的 AI 预览在页面关闭或刷新后消失。

删除将清除本机频道、分类、撤销记录、AI 配置和密钥、界面偏好，并撤销可选连接权限。自动收集会暂停，直到你主动恢复。

为记住暂停状态，仅保留一条不含频道或账号的删除标记。卸载扩展会移除此标记。

已导出的文件、已发送到 AI 服务的记录和本机 CLI 账号不在此删除范围内。它们须在对应位置管理。

连接本机订阅

首次双击安装包中的“安装YouTube分类小助手.app”，核对上方扩展 ID 并安装。安装器会自动查找 Codex／Claude 命令，不要求安装 Python。

返回本页检测小助手，选择 Codex 或 Claude 并保存。以后在 YouTube 点击“生成分类建议”，浏览器会自动启动小助手并调用已登录的官方命令行工具。

请求仍可能发送到对应云服务并消耗账号额度。小助手按需退出，不监听端口，不设置开机启动。命令存在不代表账号已经登录。

发送哪些信息

点击生成建议时，按所选范围分批发送频道名称、地址、已收集简介、现有分类名称和你填写的分类要求。处理全部频道会产生多次请求，可能消耗更多账号额度。

云端 API 密钥保存在扩展本地存储中，不会加入频道备份，也不会提供给 YouTube 页面。此存储不是操作系统密码库。本机模式不保存订阅账号密钥。

云端地址可填 API 基础地址或完整的 Chat Completions 地址。保存时只申请连接该主机的权限。
